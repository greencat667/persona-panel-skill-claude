# Contributing to Persona Panel / Persona Swarm

Thanks for your interest in improving these skills.

**This repo is not actively maintained.** It was published as a one-time release, not something
I'm committed to reviewing or updating on an ongoing basis. Issues and PRs may sit unanswered for
a long time, or indefinitely. If you need changes, forking is likely faster than waiting on a
response here.

## What's most useful

- A refinement to the persona-quality checks (the "could you swap this persona into any other topic" test)
- A fix to the swarm's round-sampling logic or JSON state format
- A second eval scenario for either skill, in a different domain
- Improvements to the HTML report/timeline visualisation

## How to contribute

1. Fork the repository
2. Create a branch (`git checkout -b improvement/your-change`)
3. Make your changes
4. Open a pull request with a clear description of what you changed and why

## What to avoid

- Changes specific to one organisation's branding or workflow — keep it general
- Real internal scenarios, quotes, or data as examples — keep worked examples fictional or clearly your own to publish
- Softening the "range over consensus" goal — hostile and indifferent reactions are the point, not a bug

## Questions?

Open an issue if you like, but see the note above — don't expect a quick reply.
